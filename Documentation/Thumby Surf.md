# Thumby Surf

> Reference: Thumby Random/Thumby Surf/Thumby Surf.py

Thumby Surf is an endless surfer game for the original Thumby. It combines a side-scrolling obstacle course, score tracking, audio cues, and a persistent high-score system.

## Purpose

The project plays like a compact arcade game: the player controls a surfer, dodges obstacles, and tries to survive as long as possible while the world scrolls forward.

## Main systems

- wave motion and background animation
- player movement and boosting logic
- obstacle generation and collision detection
- audio cues for title screen, game events, and milestone triggers
- persistent save data for high score storage

## User experience

The game starts with a title screen, then moves to an active run. Player input controls vertical movement and boost timing while obstacles scroll toward the surfer. It also includes milestone text and a celebratory message when the score threshold is reached.

> The game balances arcade challenge with simple, readable visuals suitable for a tiny monochrome screen.

## Notes

This project shows a strong focus on polished gameplay feel: title music, score persistence, responsive controls, and a compact UI are all built into a single script.
